## 🔬 Research Interests

- **Camera–radar sensor fusion** — BEV-space feature alignment under sparse and noisy radar returns
- **Cross-modal knowledge distillation** — transferring camera/LiDAR geometric priors into radar-centric inference
- **Radar preprocessing** — exploiting per-point metadata (RCS, ambiguity state, dynamic properties) that standard pipelines discard
- **On-vehicle deployment** — quantization, TensorRT inference, and the latency/accuracy trade-offs that decide whether a perception model ships
